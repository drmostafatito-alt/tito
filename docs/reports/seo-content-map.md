## 1. المنهجية (Mapping Rules)

### 1.1 مصدر الحقيقة
- **البراند:** إعدادات المنصة (Appearance → Identity) — د/ مصطفى تيتو
- **الدروس الحقيقية:** 48 درس من `docs/seo/keyword-universe.csv` — أسماء الدروس كما هي، لا استبدال
- **المواد والصفوف:** صفوف `grades`, `subjects` المنشورة في DB (published, non-deleted, مع parent منشور)
- **الكلمات الدلالية:** من عمود `الكلمات الدلالية` في CSV — تُستخدم لبناء topical authority

### 1.2 Canonical Strategy (واحد قوي لكل Intent)
| Intent | Canonical Target | السبب |
|--------|-----------------|-------|
| branded (مصطفى تيتو) | `/` | Homepage is brand-core |
| brand_entity (دكتور مصطفى تيتو) | `/about` | Person + ProfilePage |
| subject (فلسفة ومنطق) | `/subjects/:slug` | Subject page يحمل المادة + الصف في title |
| grade (الصف الأول الثانوي) | `/grades/:slug` | Grade page cross-links للمواد |
| grade_subject (أولى ثانوي فلسفة) | `/subjects/:slug` (title = مادة — صف — براند) | Subject wins, grade في title + breadcrumb |
| course (كورس) | `/courses/:slug` | Course page هو شرح/محاضرة |
| unit (وحدة) | `/courses/:slug/units/:unitId` | Unit page public, lists lessons, indexable |
| lesson_discovery | `/courses/:slug/units/:unitId` | Lesson titles public في unit page, lesson content private (learn noindex) |
| lesson_explanation / summary / revision / video / pdf / academic_year | `/courses/:slug` | كورس واحد قوي لكل صيغ البحث |
| lesson_questions / exam / practice | `/courses/:slug` (داخل تيتو) → external Questions Platform | Tito لا يستضيف أسئلة — entry point في course page |
| resources (ملخص PDF) | `/p/resources` + subject page | مكتبة المصادر |
| academic_year (فلسفة 2026) | نفس الصفحات الديناميكية (year في metadata فقط) | لا year في URL, no doorway |

### 1.3 صيغ البحث الطبيعية المغطاة
لكل درس حقيقي نغطي:
- شرح، ملخص، مراجعة، أسئلة، امتحان، تدريبات، حل أسئلة، فيديو شرح، PDF
- + المادة والصف والسنة واسم مصطفى تيتو عندما يكون منطقيًا
- مثال: "شرح معنى التفكير الإنساني أولى ثانوي مصطفى تيتو"، "ملخص نشأة علم النفس PDF"، "مراجعة الذكاءات المتعددة بكالوريا"

## 10. Topical Authority Implementation

Google يفهم العلاقة عبر:
- **BreadcrumbList** كامل: الرئيسية → البرامج → الصف → المادة → الكورس → الوحدة (من realLessons + DB)
- **Course JSON-LD** مع `hasPart` للوحدات، `teaches` للمفاهيم من CSV، `educationalLevel` للصف
- **LearningResource** للوحدات والدروس
- **DefinedTermSet** للمفاهيم الدلالية (semantic من CSV)
- **Person** مع `knowsAbout`: ["فلسفة", "علم نفس", "منطق", "فلسفة ومنطق", "بكالوريا"]

```
مصطفى تيتو (Person, knowsAbout: فلسفة ومنطق، علم نفس، بكالوريا)
  → منصة Tito (Organization, WebSite)
    → المادة (Subject: فلسفة ومنطق / علم النفس)
      → الصف (Grade: الصف الأول الثانوي / مرحلة البكالوريا المصرية)
        → الترم/الجزء (Term: الترم الأول، الترم الثاني، الجزء الأول، الجزء الثاني)
          → الوحدة (Unit: الوحدة الأولى: الفلسفة، الوحدة الثانية: المنطق، ...)
            → الفصل (Chapter: الفصل الأول: التفكير الإنساني، ...)
              → الدرس (Lesson: معنى التفكير الإنساني وتطبيقاته، ...)
                → المفاهيم (Concepts: من عمود الكلمات الدلالية في CSV)
```

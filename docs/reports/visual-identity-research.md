## PART 1 — References studied (15)

### R1 — The School of Life (theschooloflife.com) — philosophy/psychology education
- **Typography:** warm humanist sans + serif article titles; generous line-height (~1.8) for long reads.
- **Hierarchy:** kicker (topic) → large calm title → long-form body; content is the hero.
- **Color:** warm neutrals (cream/stone), muted orange accent used sparingly.
- **Whitespace:** very generous; article column narrow (~65ch), huge section air.
- **Navigation:** quiet top bar, topic index; no shouting.
- **Hero:** often *typographic only* — a sentence, not a dashboard mockup.
- **Sections:** rhythm of essay → exercise → book → class; dividers are whitespace, not boxes.
- **Cards:** rare; when used, flat with hairline borders, never glossy.
- **Imagery:** classical art + muted illustration; captioned like a museum plate.
- **Buttons:** simple solid pills/rects, one primary action per view.
- **Editorial elements:** numbered essays, pull-quotes, topic taxonomies.
- **Mobile:** single column, type scales down gracefully, sticky minimal nav.
- **Personality:** wise friend; calm, literate, humane.
- **Takeaway:** *الصمت البصري ثقة. المقال هو البطل، والقسم يُفصل بالهواء لا بالصناديق.*

### R2 — MasterClass — premium instructor-led learning

- **Hierarchy:** instructor name > course promise > trailer CTA.
- **Color:** near-black stage, white type, single red accent.
- **Whitespace:** cinematic full-bleed chapters separated by black air.
- **Navigation:** minimal chrome over video; content owns the screen.
- **Hero:** full-screen motion portrait of the teacher — *the human is the brand*.
- **Sections:** chapters like film acts; trailers before curriculum lists.
- **Cards:** poster-like 16:9 frames, image-first, minimal text.
- **Imagery:** portraiture, shallow depth, warm cinematic grade.
- **Buttons:** one loud CTA (red) + quiet ghost secondary.
- **Mobile:** vertical video-first, thumb-zone CTAs.
- **Personality:** Hollywood of learning; aspirational, intense.
- **Takeaway:** *وجّه الكاميرا للمعلم: صورة شخصية حقيقية + اسم بخط عرض قوي = علامة لا تُنسى.*

### R4 — Aesop — premium whitespace brand

### R15 — Arabic type research (Ehab Fayez 2026 guide, arabickeyboard comparison, calligraphy survey)
- **Roles:** Amiri = long-form/print/scholarly · Cairo = interfaces · Tajawal/Almarai = screen body · Reem Kufi = headings only · Markazi Text = editorial columns · Aref Ruqaa = personal/handwritten · Scheherazade New = vowelled teaching text.
- **Pairing rule:** match *color* (darkness), not classification — Amiri ↔ Source Serif; Cairo ↔ Inter/Poppins; Reem Kufi ↔ Playfair Display.

- **Takeaway:** *نظام الخطوط: نسخي علمي للعرض (Amiri) + هندسي نظيف للواجهة (Cairo/Plex) + serif لاتيني تحريري (Fraunces).*

## PART 2 — Common principles (extracted)

1. **Content is the hero** — typography + whitespace carry the page; cards are rationed.
2. **Two type voices max** — display serif with character + quiet sans for UI/body.
3. **Restrained palette** — paper + ink + one deep institutional color + one metallic accent (gold/brass).
4. **Editorial devices** — kickers with rules, bylines, numerals, pull-quotes, hairline dividers, indexes over grids.
5. **Asymmetry & rhythm** — alternating alignments, one idea per section, air between acts.
6. **Real human imagery** — portraits and artifacts, captioned like plates; no AI-illustration look.
7. **Quiet chrome** — text-first navigation, ghost actions, one loud CTA per view.
8. **Honest numbers** — stats as proof with context, never decoration.
9. **Mobile = re-composition** — single calm column, preserved air, thumb-zone actions (not shrunk desktop).
10. **Consistency = trust** — one radius language, one shadow language, one spacing scale everywhere.

## PART 4 — Proposed design direction: «المَجْلِس» (The Sage's Majlis)

### Personality (5 words)
**وقور · دافئ · عميق · إنساني · أصيل**
Dignified · Warm · Profound · Human · Authentic — *Sage archetype, not entertainer, not clerk.*

### Color system — "Paper, Ink & Brass"
| Token | Value | Role |
|---|---|---|
| `background` | `#F6F1E7` paper | warm book-paper page |
| `surface` | `#FFFDF8` parchment | cards, sheets |
| `surface-alt` | sand `#ECE4D2` (derived) | wells, figure mats |
| `primary` (brand base) | `#0E6B5E` pine ink | deep scholarly teal-green |
| `secondary` | `#123B3B` abyss pine | dark text/ink band, brand-700/800 |
| `accent` (gold base) | `#C9A227` brass | kickers, rules, seals, numerals |
| `text` | `#211B14` warm ink | |
| `mutedText` | `#6F6455` warm stone | |
| `border` | `#E3DACA` sand line | hairlines |
| `success` | `#047857` | `warning` `#B45309` · `error` `#B91C1C` (warm-shifted) |

Why: deep pine = trust/depth/calm (psychology), brass = wisdom/achievement (philosophy), paper = the book. Zero violet/blue SaaS residue. All warm-shifted so Arabic Naskh ink feels printed, not rendered.

### Typography system — "The Scholar's Voice"
| Role | Arabic | Latin | Notes |
|---|---|---|---|
| **Display** (hero, brand, quotes, section titles) | **El Messiri 600/700** | **Fraunces variable** (wght+opsz) | modern calligraphic AR ↔ editorial serif EN; matched color · **owner-approved 2026-09-08** |
| Headings UI (cards, tables, dashboard) | Cairo 700 | Cairo/Plex 600 | geometric clarity where scanning matters |
| Body | IBM Plex Sans Arabic 400/500 | IBM Plex Sans 400/500 | proven screen readability (kept) |
| Kickers/labels | Plex 600, letterspaced, with brass rule | same, small-caps feel | editorial index voice |
| Buttons | Plex 600 | Plex 600 | never serif (usability) |
| Numerals (stats) | tabular Plex; display numerals Amiri/Fraunces | Fraunces for hero stats | |

**Why Amiri:** classical Naskh revival of the Bulaq Press tradition — the typeface of Arabic scholarly books; excellent diacritics (matters for philosophy terms/Qu'ran-adjacent quotes); OFL; readable at display sizes; instantly signals "this is a place of learning, not a SaaS". Body stays sans so long UI sessions stay effortless.

### Brand treatment — «د. مصطفى تيتو»
- Official naming everywhere: **د. مصطفى تيتو** / **Dr. Mostafa Tito** (fix all `د/` + lowercase variants).
- Lockup: **signet roundel** — ink disc, thin brass inner ring, Amiri letter «م» (a personal wax-seal / ختم) + name set in **Amiri Bold**, with a micro-kicker beneath: `الفلسفة · علم النفس` / `PHILOSOPHY · PSYCHOLOGY` in letterspaced Plex with brass rules.
- No gradients, no shadows on the mark. The seal works at 32px and on paper.

### Design system rules
- **Radius:** editorial-sharp — base 10 · button 10 · card 16. No full-pill buttons/nav (pills = SaaS tell); chips stay pill only as *tags*.
- **Shadows:** `sm` default; `md` only for floating layers; hairline borders do the separation work.
- **Buttons:** Primary = pine-ink solid + paper text; Secondary = 1px ink outline; Ghost = text with underline-offset hover; link-arrows `→/←` RTL-aware with hover nudge.
- **Sections:** alternate paper / parchment / **ink band** (deep pine, paper text, brass rules) for quotes + final CTA. Section header pattern: brass kicker + Amiri/Fraunces title + short dek. Max measures: prose 65ch, sections 72rem.
- **Imagery:** framed-plate treatment — parchment mat + hairline + serif italic caption; sepia-safe (no duotone forcing on owner photos).
- **CMS richtext:** measure 65ch, drop cap on article pages, styled pull-quotes (`>`) with brass border-start, `h2/h3` in display face.
- **Motion:** stillness-first; only 150–200ms color/underline transitions + arrow nudges. No parallax/float loops.
- **Breakpoints:** sm 640 · md 768 · lg 1024 · xl 1280 (Tailwind default); mobile recomposes to one calm column with preserved air.

### Surfaces rollout (visual layer only — zero logic changes)
1. Tokens (`app.css` @theme + `themeSettingsSchema` defaults + `seed.mjs` theme) → 2. Fonts (Fontsource Amiri + Fraunces, subset-scoped) → 3. Brand/seal + header/footer → 4. Homepage CMS blocks (hero_showcase, statistics-bar→ink band, feature_cards→editorial index, testimonials→pull-quotes, buttons, richtext) → 5. Shared UI (Button/Card/Badge/Input/Alert/EmptyState) → 6. Courses/catalog/detail → 7. Lesson → 8. Auth → 9. Dashboard → 10. Remaining public + error/empty states → 11. Browser QA (ar/en × desktop/mobile) + tests.

### CMS compatibility guarantees
- No block removed, no prop renamed, no schema narrowed; only renderers' *visual* classes change.
- All owner content (menus, videos, forms, images, localization, theme tokens) untouched and still authoritative; `/theme.css` still overrides tokens (new palette ships as *defaults* — existing DBs adopt on re-seed or one-click Appearance save; documented in final report).
- Theme enums extended additively only (if at all).
